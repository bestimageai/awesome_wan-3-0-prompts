# Wan 3.0 模型与平台兼容说明

由 [bestimage.ai](https://bestimage.ai/) 团队整理。[返回主介绍](../README.md)

本指南区分三种信息：阿里云对模型的公开说明、bestimage.ai 当前页面与 API 的具体接口约定，以及本库的创作要求。三者不能互相代替，也不能把旧版 Wan 的能力直接归给 Wan 3.0。

## 1. 官方资料确认到哪一层

阿里云 [Wan 3.0 发布介绍](https://modelstudio.alibabacloud.com/intl/blog/wan3-ai-video-generation-model/)介绍最长 30 秒视频、多模态参考输入及视听生成；官方 [视频生成与编辑模型文档](https://www.alibabacloud.com/help/en/model-studio/video-generate-edit-model)用于继续核对型号、地区和模式。这些资料支持模型能力方向，但不是 bestimage.ai 的请求字段规范。

不能根据开源 Wan 历史项目，推断 Wan 3.0 权重已开放、可以本地部署或沿用旧许可证。也不宣称精确物理模拟、人物身份绝对不变、手语正确、严格逐帧配音或任意画面文字都能可靠完成。

## 2. bestimage.ai 的四个文档入口

| 模式 | 模型入口 | 输入重点 |
|---|---|---|
| 文生视频 | [Wan 3.0 Text to Video](https://bestimage.ai/models/alibaba/wan-3-0-text-to-video/) | 文本、时长、分辨率、画幅、声音、种子 |
| 图生视频 | [Wan 3.0 Image to Video](https://bestimage.ai/models/alibaba/wan-3-0-image-to-video/) | 当前文档要求首图和尾图，不能只交一张图 |
| 参考生视频 | [Wan 3.0 Reference to Video](https://bestimage.ai/models/alibaba/wan-3-0-reference-to-video/) | 可选人物、物体、场景、动作、声音、文件或网页参考 |
| 视频编辑 | [Wan 3.0 Video Edit](https://bestimage.ai/models/alibaba/wan-3-0-video-edit/) | 原视频与明确的局部修改要求 |

模型页面提供对应模式和接口说明。使用前请查看所选模型的账户权限、输入要求和当前价格。

具体 API 约定见 [bestimage.ai Wan 文档](https://bestimage.ai/docs/?page=api%2Fwan-3-0)和本库的[英文接入指南](bestimage-wan-3-api.md)。API 主机为 `https://api.flaq.ai`，请使用在 bestimage.ai 账户中获取的 API 密钥。

## 3. 当前平台限制摘要

| 项目 | 文档中的限制与本库处理 |
|---|---|
| 输出 | 2–30 秒；480p、720p、1080p；16:9、9:16、1:1、4:3、3:4 |
| 声音 | `sound` 可选，文档默认开启；无声条目应显式关闭 |
| 首尾帧 | `image_url` 与 `image_end_url` 均需提供；首尾状态应能合理连续变化 |
| 图片 | JPEG/JPG、无 alpha 的 PNG、BMP、WebP；单边 240–8000 像素 |
| 编辑原片 | MP4/MOV、最长 15 秒、单边 240–4096 像素；**原片时长＋输出时长 ≤30 秒** |
| 参考数量 | 图片最多 10 张、视频最多 5 个、音频最多 5 个 |
| 参考时长 | 单个视频或音频 1–15 秒；**视频集合总时长 ≤15 秒，音频集合总时长另计且 ≤15 秒** |
| 文件与网页 | `files`、`links` 各最多一个，二者互斥；文件类型、页数和地区访问条件另查文档 |

时长与画幅必须通过界面或 API 设置，不能只写在提示词里。提示词中的“10 秒”“声音关闭”“左边说话者”等是创作意图，不会代替请求字段校验，也不能强制模型产生合格结果。

## 4. 提示词能力如何验收

| 创作要求 | 需要核对的实际结果 |
|---|---|
| 时间分段、多镜头 | 动作是否按顺序推进、镜头有无跳跃；不是每段时间都保证精确 |
| 身份与物体参考 | 脸、衣服、几何、材料是否稳定；不能只看第一帧 |
| 动作参考视频 | 是否只借用指定节奏，是否误带入背景、服饰或人物 |
| 首尾帧过渡 | 中间过程有无凭空增物、体积失衡、瞬移或不合理变形 |
| 对白和语言 | 说话者、停顿、语言、声音与口型是否对应；需实际听审 |
| 局部视频编辑 | 非目标区域是否漂移；不能把“保持不变”的指令当作像素保证 |
| 科学、工业和无障碍场景 | 专业人员核对事实、动作和实际使用条件；概念图不能替代测量与认证 |

若指定入口不支持所需能力，先明确缺项，再由使用者决定是否调整工作流。本库不自动更换模型、不把单首帧模式冒充首尾帧、不把静态图冒充生成视频；未确认的专业配音、动作克隆或手语任务也不宣称可用。

## 5. GPT Image 2 与素材来源

[GPT Image 2](https://bestimage.ai/models/openai/gpt-image-2/)和[编辑版本](https://bestimage.ai/models/openai/gpt-image-2-edit/)是单独的图像模型入口，可用于先设计、审查角色或商品参考帧。它们不是 Wan 视频接口，也不代表这里已经实现了自动串联。

本仓库的 8 张新图片来自内置图像生成工具；工具没有公开底层模型 ID。它们是静态概念图，不是 Wan 3.0 输出或 GPT Image 2 API 调用结果。每张的用途、完整生成提示词和修改记录见[素材说明](../assets/README.md)。

## 每次执行前检查

1. 模型名称、平台、地区和当前账户是否与文档一致。
2. 输入角色、素材权利、文件尺寸、数量及总时长是否合规。
3. 编辑原片与目标时长的和是否合规，文件与网页是否混用。
4. 是否需要声音，准确台词由谁说，其他人何时保持安静。
5. 当前价格、失败计费、素材保留期和并发限制。
6. 输出由谁验收，哪些内容需要语言、科学、安全或产品专业复核。

更新事实时请提供来源、核对日期和适用入口，不只引用仓库标题、搜索摘要或营销承诺。
