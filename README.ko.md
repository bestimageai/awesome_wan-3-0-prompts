## 수록 범위와 시작 방법

15개 언어로 입문 안내와 동일한 비교 프롬프트를 제공합니다. **148개 연출안 전체를 15개 언어로 번역한 것은 아닙니다.** 첫 6개 범주는 중국어, 나머지 8개 범주는 영어로 작성되어 있습니다. 비교 프롬프트와 번역본은 추가 장면 수에 포함하지 않습니다.

색인에서 연출안을 고르고 세부 사항을 조정한 뒤 입력 자료를 준비하세요. 참조 자료 설명은 역할을 뜻하며 해당 파일을 저장소에서 제공한다는 의미는 아닙니다. 길이, 화면비, 해상도, 사운드는 선택한 화면이나 요청 필드에서 설정해야 합니다. 프롬프트에 적는 것만으로 API가 설정되지 않습니다. 소규모로 시험한 후 동작, 형태, 인물의 동일성, 타이밍, 사운드를 점검하세요.

## 8단계 프롬프트 구조

```text
[출력] 길이 + 화면비 + 시각 표현 방식
[주체] 고정된 식별 특징 + 의상이나 재질 + 바꾸면 안 되는 세부 사항
[환경] 시간 + 장소 + 날씨 + 공간의 층위
[동작] 계기 → 연속 동작 → 눈에 보이는 결과
[카메라] 샷 크기 + 위치 + 하나의 이동 경로 + 마지막 구도
[시각] 빛 + 색 + 질감 + 동작 흐림
[사운드] 환경음 + 동작음 + 음악 + 대사 언어（지원되는 경우）
[제약] 유지할 요소 + 피해야 할 문제
```

## 완전한 비교 프롬프트

**방식:** 텍스트로 영상 생성 · **설정:** 10초, 16:9, 사운드 켜기 · **입력 자료:** 없음

```text
조용한 지역사회 공구 대여소를 배경으로 10초 길이의 16:9 다큐멘터리 샷을 만든다. 짧은 곱슬머리의 성인 자원봉사자 한 명이 겨자색 앞치마와 소매를 걷어 올린 남색 셔츠를 입고 작은 빨간색 탁상용 선풍기를 수리한다. 선풍기는 처음부터 끝까지 플러그를 뽑아 둔다. 0–3초에는 떼어 낸 보호망을 멈춰 있는 선풍기 옆에 놓는다. 3–7초에는 부드러운 천으로 날개 하나의 먼지를 닦고, 카메라는 탁자 높이에서 오른쪽으로 천천히 이동한다. 7–10초에는 천을 내려놓고 보호망을 본체에 맞추되, 플러그를 꽂거나 선풍기를 작동시키지 않는다. 창문으로 들어오는 빛이 낡은 금속과 면직물의 질감을 드러낸다. 사운드는 천으로 문지르는 소리, 보호망이 작게 딸깍하는 소리 한 번, 조용한 실내 환경음뿐이다. 말소리나 음악은 없다. 동일한 인물과 선풍기, 날개 세 개, 빨간색 본체, 플러그를 뽑아 둔 전원선을 유지한다. 회전하는 날개, 추가 공구, 읽을 수 있는 라벨, 자막, 컷 전환은 넣지 않는다.
```

**조정 항목:** 앞치마 색, 선풍기 색, 실내 조명. **검토 항목:** 선풍기는 계속 플러그가 빠진 채 정지해 있어야 하며, 날개 수와 손의 접촉 관계가 일관되어야 합니다. 창작 장면이며 전기제품 수리 지침이 아닙니다.

## bestimage.ai의 Wan 3.0 API 선택

| 경로（영어 모델 페이지） | 입력 및 검토 사항 |
|---|---|
| [텍스트로 영상 생성](https://bestimage.ai/models/alibaba/wan-3-0-text-to-video/) | 한 사건의 원인, 중간 동작, 눈에 보이는 결과를 완전하게 설명 |
| [이미지로 영상 생성](https://bestimage.ai/models/alibaba/wan-3-0-image-to-video/) | 이 플랫폼의 문서에서는 시작 이미지**와 끝 이미지**를 요구함. 물리적 전환을 설명하고 구조와 구도를 고정 |
| [참조 자료로 영상 생성](https://bestimage.ai/models/alibaba/wan-3-0-reference-to-video/) | 인물, 사물, 공간, 동작, 소리 참조에 각각 명확한 역할 하나를 지정 |
| [영상 편집](https://bestimage.ai/models/alibaba/wan-3-0-video-edit/) | 원본 영상과 범위를 한정한 변경 하나를 준비하고 연기, 길이, 카메라, 나머지 영역을 유지 |

모델 페이지에서 현재 인터페이스와 공개 요청 예시를 확인할 수 있습니다. 모든 Wan 제품에 같은 제어 기능이 있는 것은 아닙니다. [기능과 제한](guides/model-capabilities.md)을 참고하세요.

영어로 작성된 [API 절차 및 비용 관리 가이드](guides/bestimage-wan-3-api.md)는 요청, 폴링, 입력 검증, 시험 계획을 설명합니다. **bestimage.ai의 API 호스트는 `https://api.flaq.ai`입니다.** bestimage.ai 계정에서 발급받은 API 키를 사용하세요. 크레딧을 쓰기 전에 모델 페이지와 계정에서 최신 요금과 이용 조건을 확인하세요.

## GPT Image 2로 참조 프레임 준비

[GPT Image 2](https://bestimage.ai/models/openai/gpt-image-2/)는 정지 이미지를 생성하며, [GPT Image 2 Edit](https://bestimage.ai/models/openai/gpt-image-2-edit/)는 이미지를 편집하고 시각 참조를 결합합니다. 캐릭터 설정 이미지, 제품 참조, 승인된 시작·끝 구도를 준비하고 내보낸 이미지를 검토한 뒤 알맞은 Wan 경로에 전달하세요.

이는 **별도의 이미지 모델**이며 Wan 영상 API가 아닙니다. 저장소는 이 전달 과정을 자동화하지 않으며, 개념 이미지가 해당 API로 생성되었다고 주장하지도 않습니다. [참조 프레임 작업 절차](guides/bestimage-wan-3-api.md#gpt-image-2-reference-frame-workflow)를 참고하세요.
