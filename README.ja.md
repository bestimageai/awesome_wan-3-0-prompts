## 収録範囲と始め方

15 言語の入口ガイドと同じ比較用プロンプトの翻訳を用意していますが、**148 本すべての翻訳ではありません**。最初の 6 カテゴリの本文は中国語、残り 8 カテゴリは英語です。比較用プロンプトと翻訳は、追加シーン数に含みません。

索引からブリーフを選び、調整項目を書き換えて必要な入力素材を準備します。参照素材の指定は役割の説明であり、ファイルが同梱されているわけではありません。秒数、画面比率、解像度、音声は利用画面またはリクエストの項目で設定してください。プロンプトに書くだけでは API 設定になりません。少量の試作後、動作、形状、人物の同一性、タイミング、音を確認します。

## 8 層の基本フォーマット

```text
[出力] 秒数 + アスペクト比 + 映像表現
[主体] 同一性を保つ特徴 + 衣装や素材 + 変えてはいけない要素
[環境] 時間 + 場所 + 天候 + 空間の層
[動作] きっかけ → 連続動作 → 目に見える結果
[カメラ] ショットサイズ + 位置 + 一つの移動経路 + 最終構図
[画作り] 光 + 色 + 質感 + モーションブラー
[音] 環境音 + 動作音 + 音楽 + セリフの言語（対応する場合）
[制約] 保持するもの + 避ける問題
```

## 完全な比較用プロンプト

**方式：**テキストから動画生成 · **設定：**10 秒、16:9、音声あり · **入力素材：**なし

```text
静かな地域の工具貸出施設を舞台に、10 秒、16:9 のドキュメンタリーショットを作る。短い巻き毛の成人ボランティアが、マスタード色のエプロンと袖をまくったネイビーブルーのシャツを着て、小さな赤い卓上扇風機を修理している。扇風機のプラグは終始抜いたままにする。0–3 秒では、取り外した保護カバーを、停止した扇風機の隣に置く。3–7 秒では、柔らかい布で羽根 1 枚のほこりを拭き取り、カメラは卓上の高さでゆっくり右へ移動する。7–10 秒では、布を置いてカバーを本体に合わせるが、プラグは差し込まず、扇風機も動かさない。窓からの光が、使い込まれた金属と綿布の質感を照らす。音は布で擦る音、カバーの小さなカチッという音が一度、静かな室内の環境音のみ。会話も音楽もない。同じ人物、同じ扇風機、3 枚の羽根、赤い本体、抜いたままの電源コードを保つ。回転する羽根、余分な工具、読めるラベル、字幕、カットは入れない。
```

**調整項目：**エプロンの色、扇風機の色、室内の光。**確認項目：**扇風機はプラグを抜いたまま停止していること、羽根の枚数と手の接触が一貫していること。これは創作上の場面であり、電気製品の修理手順ではありません。

## bestimage.ai の Wan 3.0 API を選ぶ

| 入口（英語のモデルページ） | 入力と確認事項 |
|---|---|
| [テキストから動画生成](https://bestimage.ai/models/alibaba/wan-3-0-text-to-video/) | 一つの出来事について、原因、途中の動作、見える結果を記述 |
| [画像から動画生成](https://bestimage.ai/models/alibaba/wan-3-0-image-to-video/) | このサービスの文書では開始画像**と終了画像**が必要。形状と構図を固定し、物理的な移行を説明 |
| [参照素材から動画生成](https://bestimage.ai/models/alibaba/wan-3-0-reference-to-video/) | 人物、物体、空間、動作、音の各参照に一つの明確な役割を割り当てる |
| [動画編集](https://bestimage.ai/models/alibaba/wan-3-0-video-edit/) | 元の動画と限定した変更を一つ用意し、演技、長さ、カメラ、変更しない領域を保持 |

モデルページでは、現在の操作画面と公開リクエスト例を確認できます。すべての Wan 製品で同じ設定が使えるとは限りません。[機能と制約](guides/model-capabilities.md)をご確認ください。

[API の流れと費用管理ガイド](guides/bestimage-wan-3-api.md)は英語で、リクエスト、ポーリング、入力の検査、試作計画を扱います。**bestimage.ai の API ホストは `https://api.flaq.ai` です。** bestimage.ai アカウントで発行した API キーを使用してください。クレジットを使う前に、モデルページとアカウントで最新の料金や利用条件を確認してください。

## GPT Image 2 で参照フレームを準備する

[GPT Image 2](https://bestimage.ai/models/openai/gpt-image-2/)は静止画を生成し、[GPT Image 2 Edit](https://bestimage.ai/models/openai/gpt-image-2-edit/)は画像を編集して視覚的な参照を組み合わせます。キャラクター設定画、商品参照、承認済みの開始・終了構図を準備し、書き出して確認した画像を対応する Wan の入口に渡します。

これらは **Wan の動画 API とは別の画像モデル**です。本庫は受け渡しを自動化しておらず、掲載のコンセプト画をこれらの API で生成したとも主張していません。[参照フレームの制作手順](guides/bestimage-wan-3-api.md#gpt-image-2-reference-frame-workflow)をご覧ください。
