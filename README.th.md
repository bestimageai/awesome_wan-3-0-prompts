## ขอบเขตเนื้อหาและการเริ่มต้น

มีคู่มือเริ่มต้นและคำแปลพรอมต์เปรียบเทียบฉากเดียวกันใน 15 ภาษา **ไม่ได้แปลแนวทางทั้ง 148 รายการครบทุกภาษา** เนื้อหา 6 หมวดแรกเป็นภาษาจีน ส่วนอีก 8 หมวดเป็นภาษาอังกฤษ พรอมต์เปรียบเทียบและคำแปลไม่นับเป็นรายการใหม่เพิ่มเติม

เลือกแนวทางจากดัชนี ปรับรายละเอียด และเตรียมข้อมูลนำเข้าให้ครบ คำอธิบายข้อมูลอ้างอิงระบุหน้าที่ของไฟล์ ไม่ได้หมายความว่าคลังนี้มีไฟล์ให้ ตั้งระยะเวลา อัตราส่วนภาพ ความละเอียด และเสียงผ่านหน้าจอหรือช่องข้อมูลของคำขอที่เลือก การเขียนค่าในพรอมต์อย่างเดียวไม่ได้ตั้งค่าคำขอ API ทดลองสร้างจำนวนน้อยก่อน แล้วตรวจการกระทำ รูปทรง อัตลักษณ์ จังหวะเวลา และเสียง

## โครงสร้างพรอมต์ 8 ชั้น

```text
[ผลลัพธ์] ระยะเวลา + อัตราส่วนภาพ + รูปแบบภาพ
[ตัวแบบ] ลักษณะระบุตัวตนที่คงเดิม + เสื้อผ้าหรือวัสดุ + รายละเอียดที่ห้ามเปลี่ยน
[สภาพแวดล้อม] เวลา + สถานที่ + อากาศ + ชั้นของพื้นที่
[การกระทำ] เหตุเริ่มต้น → การเคลื่อนไหวต่อเนื่อง → ผลที่มองเห็น
[กล้อง] ขนาดภาพ + ตำแหน่ง + เส้นทางเคลื่อนที่เดียว + องค์ประกอบภาพสุดท้าย
[ภาพ] แสง + สี + พื้นผิว + ความเบลอจากการเคลื่อนไหว
[เสียง] เสียงแวดล้อม + เสียงการกระทำ + ดนตรี + ภาษาบทพูด (เมื่อรองรับ)
[ข้อจำกัด] สิ่งที่ต้องคงไว้ + ปัญหาที่ต้องหลีกเลี่ยง
```

## พรอมต์เปรียบเทียบฉบับเต็ม

**โหมด:** ข้อความเป็นวิดีโอ · **การตั้งค่า:** 10 วินาที, 16:9, เปิดเสียง · **ข้อมูลนำเข้า:** ไม่มี

```text
สร้างภาพสารคดีหนึ่งช็อตยาว 10 วินาที อัตราส่วน 16:9 ในศูนย์ให้ยืมเครื่องมือของชุมชนที่เงียบสงบ อาสาสมัครผู้ใหญ่หนึ่งคนมีผมหยิกสั้น สวมผ้ากันเปื้อนสีเหลืองมัสตาร์ดและเสื้อเชิ้ตสีน้ำเงินกรมท่าพับแขน กำลังซ่อมพัดลมตั้งโต๊ะขนาดเล็กสีแดงโดยถอดปลั๊กไว้ตลอดเวลา ช่วง 0–3 วินาที อาสาสมัครวางตะแกรงป้องกันที่ถอดแล้วไว้ข้างพัดลมซึ่งหยุดนิ่ง ช่วง 3–7 วินาที ใช้ผ้านุ่มเช็ดฝุ่นจากใบพัดหนึ่งใบ ขณะที่กล้องเลื่อนไปทางขวาอย่างช้า ๆ ที่ระดับพื้นโต๊ะ ช่วง 7–10 วินาที วางผ้าลงและจัดตะแกรงให้ตรงกับตัวเรือน โดยไม่เสียบปลั๊กและไม่เปิดพัดลม แสงจากหน้าต่างเผยพื้นผิวโลหะที่มีร่องรอยการใช้งานและเนื้อผ้าฝ้าย เสียงประกอบคือเสียงผ้าเช็ด เสียงคลิกเบา ๆ จากตะแกรงหนึ่งครั้ง และเสียงบรรยากาศห้องที่เงียบสงบ ไม่มีเสียงพูดหรือดนตรี คงบุคคลเดิม พัดลมตัวเดิม ใบพัดสามใบ ตัวเรือนสีแดง และสายไฟที่ยังไม่ได้เสียบปลั๊ก ห้ามมีใบพัดหมุน เครื่องมือเพิ่มเติม ป้ายที่อ่านข้อความได้ คำบรรยาย หรือการตัดภาพ
```

**ปรับได้:** สีผ้ากันเปื้อน สีพัดลม แสงในห้อง **ตรวจสอบ:** พัดลมต้องถอดปลั๊กและหยุดนิ่งตลอด จำนวนใบพัดและจุดสัมผัสของมือต้องสอดคล้องกัน นี่คือแนวคิดสร้างสรรค์ ไม่ใช่คำแนะนำซ่อมเครื่องใช้ไฟฟ้า

## เตรียมภาพอ้างอิงด้วย GPT Image 2

[GPT Image 2](https://bestimage.ai/models/openai/gpt-image-2/) สร้างภาพนิ่ง ส่วน [GPT Image 2 Edit](https://bestimage.ai/models/openai/gpt-image-2-edit/) แก้ไขภาพและผสมข้อมูลอ้างอิงทางภาพ ใช้เตรียมภาพออกแบบตัวละคร ภาพอ้างอิงสินค้า หรือองค์ประกอบภาพเริ่มต้นและสุดท้ายที่ผ่านการตรวจแล้ว จากนั้นส่งออกและตรวจภาพก่อนส่งให้ช่องทาง Wan ที่เหมาะสม

ทั้งสองเป็น**โมเดลภาพแยกต่างหาก** ไม่ใช่ API วิดีโอของ Wan คลังนี้ไม่ได้ส่งต่อภาพโดยอัตโนมัติ และไม่ได้อ้างว่าภาพแนวคิดสร้างผ่าน API เหล่านี้ ดู[ขั้นตอนเตรียมภาพอ้างอิง](guides/bestimage-wan-3-api.md#gpt-image-2-reference-frame-workflow)
