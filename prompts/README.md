# Wan 3.0 prompt catalog — 148 directing briefs

148 video directing briefs across 14 categories, curated and maintained by the [bestimage.ai](https://bestimage.ai/) team.

The first six categories use Chinese directing text; the remaining eight use English. Translations and the shared README comparison scene are excluded from the count. Every entry states its mode, settings, input roles, copy-ready prompt, adjustable details, and review target. Bring your own authorized references; the concept illustrations do not supply every required start/end pair.
