# Language coverage

The bestimage.ai edition has **15 localized entry guides**. Each provides the prompt formula, one complete version of the same comparison scene and API entry links. The scene is the unplugged red desk fan in a community tool library.

The **148-brief catalog is not fully translated into 15 languages**. Its first six categories contain Chinese briefs; the other eight contain English briefs. The main prompting, capabilities, and troubleshooting guides remain in Simplified Chinese. The API guide is in English. The English alias `README.en.md` is navigation, not a sixteenth language or another prompt.

## API destination policy

All 15 entry guides currently link to the same **verified English** model pages. They do not imply that the destination is localized. No language prefixes were guessed. Every entry distinguishes the four Wan video routes from GPT Image 2 generation and editing for still-frame preparation. The [main API table](../README.md#wan-30-api-on-bestimageai) and [image workflow](../guides/bestimage-wan-3-api.md#gpt-image-2-reference-frame-workflow) contain the complete URL mapping.

## Translation and contribution rules

- Translate the actual finalized scene, not a previous model's or older edition's example.
- Keep time ranges, aspect ratios, reference roles, speaker assignments, object counts and immutable details intact.
- Use natural target-language wording. Do not fill untranslated paragraphs with English or mix unrelated languages.
- Preserve exact dialogue only when its language is intentionally part of a directing brief; identify it clearly.
- Do not count translations or the shared comparison scene as new catalog briefs.
- Do not silently hide a guide because another language has not been translated.
- Ask fluent reviewers to check naturalness and any specialized terminology before publication; automated checks are not native-speaker certification.
- Follow [CONTRIBUTING.md](../CONTRIBUTING.md#translations), including source attribution and media rights.
